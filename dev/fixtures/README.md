# 検証用フィクスチャ (dev/fixtures)

要素内スクロール対応を手元で再現性をもって確認するための、静的なテストページです。
本番のビルド（`dist/`）には含まれません。

## 各ページの用途

- `app-layout.html`
  Slack 風のレイアウト。ページ自体はスクロールせず、サイドバーとメッセージ一覧という
  「要素の中身」がそれぞれスクロールする構成です。祖先要素が `position: fixed` の
  場合の撮影を確認するためのものです。

- `in-page-container.html`
  ページ自体が縦にスクロールし、その途中にスクロールするコンテナ（さらにその中に
  入れ子のスクロールコンテナ）がある構成です。ページをスクロールした結果、対象の
  コンテナが画面の上端・下端からはみ出す位置に来るケースを確認するためのものです。

- `window-wide.html`
  これまでの「window 全体がスクロールする通常のページ」のリグレッション確認用です。
  横方向にもスクロールできるようにしてあり、既存の撮影・合成の挙動が変わっていない
  ことを確認します。

## 開き方

`dev/fixtures` ディレクトリで簡易サーバーを立てて開いてください。

```
cd dev/fixtures
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/app-layout.html` のように開きます。

`file://` で直接開く場合の注意: Chrome 拡張機能は既定では `file://` の
ページに対して動作しません。拡張機能の詳細画面（`chrome://extensions`）を開き、
対象の拡張機能の「ファイルの URL へのアクセスを許可する」をオンにしてください。

## 確認のポイント

各行には大きな行番号（例: `Row 001`）と、左端に細かい目盛りを表示しています。
複数タイルを撮影して1枚に合成した結果を見て、タイルの継ぎ目で行番号が

- 重複していないか（同じ行が2回写っていないか）
- 抜けていないか（連番が飛んでいないか）

を目で確認してください。行の高さは3種類（40 / 56 / 72px）を繰り返しており、
背景色も交互に変えてあるため、ズレがあれば継ぎ目で見た目が不自然になり気づきやすく
なっています。
